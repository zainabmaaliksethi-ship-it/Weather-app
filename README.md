This is a production-ready Android Weather App built with Java in Android Studio, offering real-time and accurate weather updates with a smooth user experience.
It shows current conditions, a reliable 3-day forecast with correct min/max temperatures from API data, and an 8-hour hourly forecast in proper order.
Users can manage multiple locations, add or delete cities instantly, and all changes are saved using SharedPreferences.
With a clean UI and optimized forecast logic, the app delivers a simple, fast, and dependable weather experience.
